# Барбос-стиль - одностраничник груминг-салона

Первый учебный сайт проекта «Создание Сайтов». Собран 10.11.2026.

## Что это

Статичный сайт-одностраничник (лендинг) для груминг-салона собак.
Тёплая кремово-коричневая палитра, антиква Playfair Display для заголовков,
рубленый Manrope для текста (оба с кириллицей с Google Fonts).

## Структура

- `index.html` - страница: первый экран, бегущая строка услуг, «Почему к нам»,
  услуги и цены, как проходит визит, отзывы, контакты, подвал.
- `styles.css` - весь дизайн, адаптив под телефон (375), планшет (768), десктоп.
- `main.js` - проявление блоков при прокрутке, мобильное меню.
- `public/img/` - 3 сгенерированных фото (hero-dog, grooming-hands, salon-dog-v2).
  Файл `salon-dog.png` не используется (с чужой надписью), удалить по согласованию.

## Как запустить

```
npm install   # один раз, восстанавливает папку node_modules
npm run dev   # запускает сервер разработки, адрес покажет в консоли (порт 7100)
```

## Заглушки, которые нужно заменить на реальные

- Телефон +7 (999) 000-00-00 (текстом и в href="tel:...")
- Адрес «ул. Примерная, 10» и часы работы
- Ссылки-кнопки Telegram и WhatsApp (сейчас href="#")
- Цены и состав услуг - примерные

## Важно про бренд

Цвета в styles.css (секция :root) - ЧЕРНОВЫЕ, до появления папки brand/.
Когда появится бренд (логотип, colors.md, fonts.md) - заменить значения
переменных --cream, --brown, --accent, --accent-deep и шрифты
--font-display, --font-body на брендовые.
